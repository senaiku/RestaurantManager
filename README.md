# RestaurantManager

Консольное приложение на C# (.NET 10) для управления меню и заказами ресторана.
Курсовая работа, тема №10 «Система управления рестораном».

## Возможности

- **Меню:** добавление, изменение и удаление блюд (название, описание, цена, категория).
- **Категории блюд:** добавление, переименование и удаление. Категорию, в которой есть блюда, удалить нельзя.
- **Заказы:** создание заказа с несколькими позициями, учёт количества каждого блюда, добавление и удаление позиций в новом заказе.
- **Расчёт стоимости:** стоимость позиции и всего заказа. Цена блюда фиксируется в момент заказа, поэтому последующие изменения меню не влияют на старые заказы.
- **Статусы заказа:** Новый → Готовится → Готов → Оплачен. Из любого незавершённого статуса заказ можно отменить. Недопустимые переходы блокируются.
- **Отчёт о продажах** за выбранный период или за всё время: число оплаченных и отменённых заказов, выручка, средний чек, продажи по блюдам и категориям.
- **Поиск, фильтрация и сортировка:**
  - блюда: по части названия или описания, категории, диапазону цен; сортировка по названию и цене;
  - заказы: по статусу и периоду; сортировка по дате и сумме.
- **Сохранение данных** между запусками в JSON-файл (сохраняется автоматически после каждого действия).
- **Защита от некорректного ввода** и обработка ошибок: программа не падает, а сообщает о проблеме.

## Требования

- [.NET 10 SDK](https://dotnet.microsoft.com/download)
- Git (для клонирования репозитория)

## Запуск

```bash
git clone https://github.com/senaiku/RestaurantManager.git
cd RestaurantManager
dotnet run
```

При первом запуске данных нет: сначала добавьте категории и блюда, затем создавайте заказы.

Данные хранятся в файле `restaurant_data.json`, который создаётся в папке, из которой запущена программа. Чтобы начать с чистого листа, удалите этот файл.

## Пример работы

1. **Категории → Добавить категорию:** «Салаты», «Напитки».
2. **Блюда меню → Добавить блюдо:** «Цезарь» (450 руб.), «Морс» (150 руб.).
3. **Заказы → Создать заказ:** выбрать блюда и количество.
4. **Заказы → Изменить статус заказа:** Готовится → Готов → Оплачен.
5. **Отчёт о продажах:** посмотреть выручку и популярные блюда.

## Структура проекта

```
RestaurantManager/
├── Models/       # Данные: Category, MenuItem, Order, OrderItem, OrderStatus, SalesReport, SortOrders
├── Services/     # Логика: MenuService, OrderService, ReportService
├── Storage/      # Хранение: IRepository, JsonRepository, AppData
├── UI/           # Консольный интерфейс: ConsoleApp, ConsoleHelper
└── Program.cs    # Точка входа
```

## Применение ООП

- **Инкапсуляция:** приватные поля, проверка значений в свойствах моделей, смена статуса заказа только через метод `ChangeStatus`.
- **Абстракция и полиморфизм:** сервисы работают с хранилищем через интерфейс `IRepository`, реализацию (`JsonRepository`) можно заменить без изменения остального кода.
- **Разделение ответственности:** модели, сервисы, хранилище и интерфейс вынесены в отдельные классы.
